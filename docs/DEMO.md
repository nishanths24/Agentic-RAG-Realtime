# Demo checklist

1. `python -m pip install -e ".[dev]"`
2. `python main.py index --rebuild`
3. `python main.py serve`
4. Open `http://127.0.0.1:8000`

Ask:

- Hotel reimbursement limit (documents only)
- Time in Tokyo (live time)
- Meal allowance in INR today (documents + currency)
- Paris weather and weather rebooking (weather + documents)
- 2030 World Cup (insufficient evidence)

Confirm the UI shows **From your documents**, **Live information**, and **How I answered**.
